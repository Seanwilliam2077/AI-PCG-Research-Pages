01

白盒生成管线

一张概念图进,一个白盒关卡出 — 再把它变成夜跑几百个场景的生产线,并延伸到数据与视频生产。

节点图与数据流

① 生图

三图供给

Text To Image 直连 Mochi / Venus 双通道,产写实航拍、语义分块、灰度高度三图;提示词四段模板锁定 90° 正交顶视,支持笔刷蒙版 + 文字指令的局部重绘;Blur 节点(高斯 / 盒式 / 中值)做入图整备。

② 矢量化

语义图 → 布局数据

Image To SVG 按 HSV 语义分类提取建筑 / 道路 / 植被 / 水体 / 边界轮廓;精度优先通路 Image To Layout Data 直接产内存布局文档,绕开 SVG 字符串解析;Char Scale 节点由骨骼网格包围盒推算角色身高,标定真实世界尺度。

③ 落地

Create PCG Data

高度图经 HeightmapLandscapeWriter 写入 Landscape,布局数据生成街区、地块与建筑白盒;SpawnObjects 统一摆放植物、围墙与道路。地形与街区共用同一个目标宽度标定,严格对齐。

Create PCG Data — 执行模型

  • 双输入可选:高度图与街区数据各自独立,任一失败不阻塞另一路,状态聚合后经 OnExecuteComplete 广播结果
  • 分帧执行:先写高度图,下一帧再生成街区,等 Landscape 碰撞就绪后才把地块贴回地形——Slate 全程可重绘不假死
  • 统一标定:TargetMapWidth 同时推导地形 XY 缩放与布局 UnitScale(目标宽 ÷ 图宽),街区与地形像素级对齐,与高度图分辨率解耦
  • 道路条带可不依赖 PCGGraph 直接沿中心线生成扁平路面,略抬高避免 Z-fighting;地块调试可视化一键收进「Show Lot Debug」开关
  • Landscape 材质层 LayerInfo 资产缺失时自动创建,免手工配置

SpawnObjects — 统一摆放

  • 植物 / 围墙 / 道路三类内容收进一个节点,Content 下拉分派,Generate 与 Clear 成对;行为与原独立节点完全一致
  • 双粒度作用域:选中单个地块,或全场景所有 Field 与 Vegetation 地块(道路按 Block 级解析)
  • 摆放规则:贴地吸附、坡向对齐、陡坡 30° 禁植、崖边台缘禁植、道路贴地形起伏——全部可按 job 覆盖
  • 植物 / 围墙 / 道路预设均为可替换的 UE 资产引用,留空则回退各 Block 已有预设
  • 区域可视化开关:植被与水体的半透明色块、道路样条,一键同步显隐

无头化与批量生产 — BatchPCG

  • 关键节点全部无头化:生图整备 / 布局转换 / 白盒落地 / 统一摆放 / 地形导出五个 Python 入口,外加地形层重置与异步收敛轮询两个配套接口
  • 三阶段编排:Phase A 云端生图(Mochi Agent 与 Venus 直连双通道)→ Phase B 编辑器内 tick 状态机(摄取→重置→整备→布局→落地→摆放→导出)→ 汇总报告
  • 每 25 个 job 重启编辑器进程规避内存累积;崩溃超时不废批,断点续跑自动跳过已完成 job,连续失败熔断防止整夜空烧
  • 启动预检逐项检查编辑器 / 工程 / 生图通道并给指引,不半路才炸;离屏后台走真 GPU 渲染,截图与状态机照常工作
  • 「万能顶视图框架」:LLM 按主题产异质化组合,近无限 prompt 供给

数据采集管线

批量能力的延伸:白盒之上自动运镜、无损渲染、坐标转换,按数据集契约落盘——原为世界模型训练数据设计,该方向未采纳落地,能力沉淀回本管线。

STAGE 1 · 2

程序化运镜

建筑群包围盒定轨道半径,地形刻意不并入(8 km 地形会把轨道推上天),相机高度下限对地形做射线检测;orbit / dolly / crane 轨迹模版按 job 随机;对焦与内参显式固定,位姿按轨迹参数解析重算,无采样误差。

STAGE 3

MRQ 无损渲染

关运动模糊与自动曝光(否则亮度时序漂移)、空间采样抗锯齿替代 TAA 避免拖影;RGB 之外经后处理材质输出 32 位 EXR 深度与世界法线;逐帧位姿与内参写 cameras.json,作为数据真源。

STAGE 4 · 5

坐标转换与打包

UE 左手系(厘米)变换到 OpenCV 相机约定(米),用合成已知位姿做单测;深度声明为沿光轴 z-depth 并换米;内参换算 K,可选逐像素 Plücker 光线;全部产物校验后按目录契约落盘。

rgb / depth / normal / cameras.json / capture_meta —— 目录 schema 即与世界模型侧的交付契约,DataLoader 按 [B,C,F,H,W] 直接组装。

一键视频批产

  • 极简前端:浏览器输入 fps / 数量 / 时长(可选主题),后台自动跑完「LLM 组合 → 三图 → PCG 白盒 → 运镜渲染 → mp4 落盘」全链,实时进度与画廊
  • 动态容量:每场景可产视频数由轨迹枚举 + 质检现算(上限可调),拍满即切下一场景,全局拍够目标即停,生图只为要用的场景付费
  • 离屏无人值守实测通过(2026.07.22):48 帧 mp4 落盘、截图非黑,单场景全链 47.5 秒
  • Phase C 自动后处理:坐标转换、编码合入画廊、默认删帧回收磁盘;进度四文件原子落盘,前端轮询聚合
  • 批处理稳态细节逐个踩平:启动参数引号与分号坑、状态机同帧重入护栏、限流退避与失败熔断
02

GeoGen — 山体与植被

地形、蒙版、城市、工具四套面板,一个编辑器模式;山体纯 AI 路线,近中景与远景互不覆盖。

GeoGen 模式 — 架构

观感对齐 Modeling Mode,机制自绘:左侧竖排分类 + 面板切换器,把三套既有大块 Slate 面板收进一个模式,业务逻辑一行未改。

地形

近中景与远景合页段选,底下是两个独立状态宿主、各持一套流水线节点——反复调远山不会覆盖近景的高度图与侵蚀结果。

蒙版

Genesis Mask Editor 整套嵌入,视口刷绘的输入回调逐条转发;懒加载,首次切入才校验 Landscape。

城市

CityGen 面板嵌入,涂刷与拖拽的视口交互整套转发;懒加载,离线服务超时不拖累地形用户。

工具

AI 生成分辨率档位(1K / 2K / 4K)一处设定、两条流水线生效;Landscape 与 StaticMesh 互转作用于视口当前选中。

山体生成 — 一键生成链

STEP 1

环绕参考图

多张参考图发给 Venus,AI 合成「中央平地、四周环山」俯视图;单体布局则直接用参考图。笔刷蒙版 + 文字指令局部重绘,客户端按蒙版权重合成,未涂抹像素逐字节保真。

STEP 2

AI 高度图

让图像模型按海拔推理成图:雪线读作高地、河谷读作最低。多图输入时按生态特征分类排序,告知模型高低关系,要求产出一块连续地形而非拼贴;8-bit 台阶由后续侵蚀掩盖。

STEP 3

侵蚀与生态蒙版

Gaea 服务器侵蚀,1024 约 20 秒、2048 约 90 秒;生态蒙版刻意排在侵蚀之后——让 AI 沿真实冲刷纹理划分植被、岩石与积雪。四步产物全是图片,零副作用可无限重来。

远景路线在侵蚀后即收尾——静态网格不吃材质分层,省一次纯浪费的生态蒙版调用。

山体生成 — 近中景落地

  • 地形面积由用户直接指定(上限 2500 km²),每格尺度在生成那一刻按面积 ÷ 高度图分辨率现算——切 1K/2K/4K 档不再让面积漂移
  • ProvisionLandscape 幂等备一块尺寸、缩放都对的空地形但不写高度;Genesis 按固定公式解读高度图,面板上的「高度落差」只能靠 Scale.Z 兑现
  • 边界包络坡角:从地形边缘零高起坡的包络线,山体只在戳破包络处削平,内部分毫不动——替代会整体压矮的第一版乘法渐变
  • 交接 Genesis:侵蚀高度图 + 16 色生态蒙版导出 PNG,尺寸对齐 Landscape 顶点数,省掉破坏性的「清空并重设」确认框
  • GenerateLandscapeOnly 只跑权重与图章两个阶段,一株草都不生成——近中景路线不为植被卷白等

山体生成 — 远景产物

  • 默认烘成单一连续静态网格:移动 / 旋转 / 缩放 / 复制全是引擎原生行为,且没有 Landscape 版的组件边界法线接缝
  • 可选烘成独立 Landscape(整体可移动),或作为「山体图章」刻进目标地形——gizmo 挪动自动重刻,删除自动还高度
  • 「提取山峰」纯本地算法:找峰 → 洪泛连通域 → 方形裁剪 + 羽化到零底座,一次抠 1–4 座独立山峰散布地平线,不重跑生成
  • 山体朝向在烘贴图时预旋转进高度场——刻录路径按轴对齐包围盒铺 UV,转 Actor 只会拉伸而山不转向
  • 显存策略:同样约 2000 顶点边长,每格 1 m 覆盖 2 km、每格 4 m 覆盖 8 km,组件数与显存完全不变;远景只看轮廓,4 m/格足够

植被生成

  • 「植被」页顶部生成生态分布图:近中景 / 远景山双来源段选,各自持有独立的侵蚀高度图与参考图
  • 16 色生态蒙版对齐 Landscape 顶点数导出,一键导入 Genesis Mask Editor,为每层绑定 PCG Graph;缺图登记表直接在面板显示
  • 植被生成只跑 VegetationOnly 阶段,不改地形高度;与山体侧的「只跑权重图章」互为镜像,互不拖累
  • 缺 MaskData 时自动先 Setup;蒙版是植被专属的可选项——造山不需要它,没导出时跳过导入,不把高度图一起拖下水
  • 摆放规则与白盒批量同源:贴地、陡坡 30° 禁植、崖边台缘禁植,交互与无头共享一套 C++ 默认

AI PCG Scene

给一张参考图,自动生成一个三维场景——三条独立实现 + 方法论 + 白盒 Live,全部开源。

单图到场景 — 三条路

线 1 · UE5 资产库匹配

AI 出提案,规则做裁决

UE 5.5 内嵌 Python 前馈管线:感知标定 → 地面射线布局 → 材质氛围 → 资产库匹配与装配;阶段间只交换 JSON、可断点续跑;匹配不上的对象退化成代理盒而不是被丢掉。127 actors / 0 报错 / 21 库命中 + 9 代理盒。

线 2 · three.js 程序化

一张图长出一整类场景

不匹配资产库:把画面拆成可生成的规则清单,几何与贴图全部在页面加载时由代码算出;同一份总平面数据被地面烘焙与三维摆放两处消费。44 897 构件 / 每帧 60 draw call,换个种子约 4 秒长出另一座。

线 3 · Blender 度量闭环

把「像不像」拆成可测量

九轮「渲染 → 度量 → 定位病因 → 改」;相机由消失点解出后定死,并投影回原图逐点核对。边缘 F 0.260 → 0.650;与线 1 外参一比,地平线差 91 px——测量推翻感觉的过程按原样留档。

github.com/Seanwilliam2077/AI-PCG-Scene —— 代码、过程留档与交互文档全部开源。

方法论与白盒 Live

  • 方法论只有一条贯穿判据:模型擅长说「这是什么」,不擅长说「这有多大、在哪里」——语义走模型,几何走算法
  • 39 个资产模块的模型估计尺寸全部挤在 75 – 118 cm 一条带里,与实测毫无关系;踩塌的结论按原样写进正文
  • 三条补召回策略贡献 49/70 检出;全部数据经脚本可复跑导出,不绑定本仓库代码
  • 白盒 Live:LSD + RANSAC 解相机,深度以地面解析单应校成米制,按视差不连续切分体块,导出 GLB 直接进 DCC
  • 推理与几何求解全部在浏览器本地完成,图片不上传;纯静态托管,打开即用
